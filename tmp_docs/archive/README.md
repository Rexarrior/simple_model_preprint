# Архив рабочих документов

Здесь лежат завершённые или заменённые рабочие планы и постановки. Они
сохранены для истории решений, но не определяют текущие задачи.

- `plans/` — завершённые планы экспериментов, редакции и визуализаций, а также
  исторический backlog;
- `handoffs/` — выполненные передачи контекста между этапами работы.

Единственный актуальный план находится в
`tmp_docs/ACTIVE_PREPRINT_PLAN.md`.
