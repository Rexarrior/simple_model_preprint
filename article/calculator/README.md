# M4 Human–Agent Workbench

Одностраничный калькулятор для фазовой модели планирования программной работы
одного разработчика с несколькими ИИ-агентами.

## Опубликованная версия

Рабочая версия артефакта опубликована на собственном VPS по адресу
[m4.articles.rexarrior.online](https://m4.articles.rexarrior.online/). Это
самостоятельное размещение, а не редирект на ChatGPT-hosted копию. Публикация
поддерживает русский и английский интерфейсы и темы `auto`, `light` и `dark`.
Исходный расчёт всегда выполняется на JavaScript в браузере; backend вызывается
только при явно включённом согласии на передачу результата.

Калькулятор принимает JSON-конфигурацию либо позволяет отредактировать классы
задач, DAG и параметры вручную. В браузере вычисляются `T_h`, `W4`, `L4`,
`gamma*H`, нижняя граница `B4` и детерминированное ресурсно-допустимое
расписание `T(pi)`. Интерфейс показывает критический путь, очередь к человеку,
диаграмму Ганта и sweep по числу агентных потоков.

Стартовый пример использует только исследования, опубликованные в 2026 году,
с приоритетом июньских и июльских работ. Базовый proxy получен из роста числа
завершённых задач в квазиэксперименте CodeFuse; поправки по классам — из
merge-rate документации, feature/behavior и infrastructure PR в AIware ’26.
Для ревью выбран нейтральный коэффициент: июльский longitudinal DiD не связал
наблюдаемое ускорение ревью именно с агентами. Интерфейс отделяет прямые замеры
от прокси и модельных допущений. Доля активного человеческого времени `q` и
координационные множители `C(P)` и `gamma(P)` не выдаются за эмпирически
измеренные величины.

## Приватность

Расчёт всегда выполняется на клиенте. Согласие «Не против поделиться
расчётами» выключено по умолчанию. Пока оно выключено, конфигурация и результат
не отправляются в API. После явного согласия и нового запуска расчёта готовые
данные сохраняются в D1 через `POST /api/share`.

Backend повторно проверяет наличие `consent: true` и версию согласия, ограничивает
размер запроса и не сохраняет IP-адрес, email или иные идентификаторы
пользователя.

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run lint
```

Тесты проверяют инвариант `B4 <= T(pi)`, отказ от циклического DAG и серверный
рендер страницы. Production-зависимости дополнительно проверяются через
`npm audit --omit=dev`.

## Хранилище

Логическое D1-подключение объявлено как `DB` в `.openai/hosting.json`.
Схема находится в `db/schema.ts`, сгенерированная миграция — в `drizzle/`.
Таблица также безопасно инициализируется на первом добровольном сохранении.

## Развёртывание на VPS

Для независимого размещения предусмотрены `Dockerfile.vps`,
`compose.vps.yaml` и конфигурация reverse proxy `vps/nginx-m4.conf`.
Web-интерфейс работает в Node.js, а добровольно переданные расчёты сохраняются
отдельным минимальным API в локальную SQLite-базу. API не журналирует адреса
посетителей и принимает данные только с явным согласием версии `v1`.
