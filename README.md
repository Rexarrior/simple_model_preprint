# Phase-Based Planning Model for Software Work in a Human--Agent Cell

Публикационный репозиторий статьи Александра Родионова о фазовом планировании
фиксированного объёма программной работы в ячейке «один разработчик — несколько
ИИ-агентов».

Текущая рукопись является русской рабочей версией. Английский перевод будет
подготовлен и проверен отдельным этапом перед международной публикацией.

## Состав репозитория

- `article/` — исходники LaTeX, библиография и полная рукопись;
- `article/experiments/` — воспроизводимый вычислительный пакет EXP-00–EXP-08,
  замороженные сценарии, тесты, результаты и генераторы рисунков;
- `article/calculator/` — M4 Human–Agent Workbench, включая исходники
  веб-интерфейса и конфигурацию независимого развёртывания;
- `article/literature_reviews/` — авторские постраничные обзоры использованных
  работ;
- `tmp_docs/` — [активный план подготовки препринта](tmp_docs/ACTIVE_PREPRINT_PLAN.md),
  поисковый протокол, evidence matrix и журналы научного аудита;
- `release/` — собранные версии рукописи для распространения.

Локальные PDF сторонних публикаций намеренно не включены: репозиторий содержит
библиографию, протокол поиска и авторские обзоры, но не распространяет чужие
полные тексты.

## Быстрая проверка

Сборка рукописи:

```bash
cd article
latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=output/pdf main.tex
```

Вычислительный пакет:

```bash
cd article/experiments
uv sync --python 3.13
uv run pytest -q
```

Калькулятор:

```bash
cd article/calculator
npm install
npm test
npm run lint
```

Подробные команды воспроизведения приведены в
[`article/experiments/README.md`](article/experiments/README.md) и в приложении
к рукописи.
